# 1. Use React for the frontend

Date: 2026-01-01

## Status

Accepted

## Context

We needed a frontend framework for this project to learn RHDH's Software Template and Catalog features hands-on.

## Decision

We will use React, since it's what the default RHDH "React" Software Template scaffolds.

## Consequences

The project gets a standard, well-documented component structure with minimal setup, at the cost of being tied to the Node.js/npm ecosystem.
